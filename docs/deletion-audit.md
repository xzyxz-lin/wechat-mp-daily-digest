# 每日删除对账

## 目的

文件总控页的“每日删除对账”放在“今日拉取状态”下方，用同一操作日的数据说明本日拉取与最终确认删除之间的关系。

## 记录范围

- 文章和基金在点击“最终确认删除”后，后端才会写入 `data/deletion_audit.json`。
- 删除仍是写入原有的可恢复删除索引，并不物理清除归档文件。
- 仅从“私人珍藏”移除标记不会改变观察台的文章或基金数据，因此不纳入拉取/删除对账。

## 面板口径

- 当日拉取论文：每日快照中的原始拉取数量。
- 当日归档删除：本操作日删除、且原本归档日期也是该日的文章数量。
- 对账后论文保留：当日拉取论文减去当日归档删除。
- 今日删除操作：本日最终确认的文章与基金删除总数；下方保留最近八条记录便于核对。

历史删除在此功能上线前没有操作时间，无法倒推填入；从本次更新起的新删除会自动登记。
