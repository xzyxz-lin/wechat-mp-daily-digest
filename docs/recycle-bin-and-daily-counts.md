# 回收站与每日分类统计说明

## 每日拉取状态

- **拉取总数** = 当日公众号文章数 + 期刊论文数 + 基金项目数。
- 下方三个卡片分别展示公众号、期刊、基金项目，来源和关键词仍在卡片下方保留，便于核对。
- 旧快照没有 `total_fetched` 字段时，前端会按三个分类字段自动计算，历史数据无需迁移。

## 每日删除对账

删除区不再重复显示上方拉取数据，也不再用“拉取后剩余”等推导数字。它只展示当日最终确认删除的四项：

1. 删除总数；
2. 公众号删除数；
3. 期刊删除数；
4. 基金项目删除数。

统计在用户完成收藏保护弹窗的最终确认后才写入，因此未收藏内容也会等到收藏内容的最终选择确定后才进入删除与统计流程。统计卡只计算**当前仍处于删除状态**的项目：从回收站恢复后会立即扣减；旧版本中已经恢复、但尚未记录恢复时间的项目，也会依据当前删除索引自动排除，避免数字永久累加。

## 回收站

- 文章或基金项目从主列表删除后，原始归档文件不会被物理删除；系统只写入删除索引和回收站记录。
- 回收站默认保留 **7 天**。到期后仅移除“可恢复记录”，内容继续保持为已删除状态。
- 功能首次启用时，会一次性补入仍在 7 天内、且仍处于删除索引的历史删除记录；手动清空或永久移出后不会被再次补入。
- 回收站按全部、公众号、期刊、基金项目分类，并显示来源、删除时间与可恢复截止时间。
- 可单项恢复，也支持多选：`Ctrl/Cmd` 点击累加单项，`Shift` 点击选择连续范围，`Ctrl/Cmd + Shift` 点击累加连续范围。
- 恢复操作会为最近一次删除事件写入恢复时间，审计历史仍保留，但不再计入“今日删除”四格统计。
- 选中后可批量恢复；“永久移出”仅移除指定回收站记录，不会恢复内容。顶部“清空回收站”同样只清除所有可恢复记录，并要求浏览器确认。

因此，回收站的“永久移出/清空”不会删除任何磁盘归档数据，但会让对应项目不再能够通过应用的回收站恢复。
